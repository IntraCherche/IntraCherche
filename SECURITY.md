# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

- Preferred: use GitHub's **private vulnerability reporting** (the "Report a vulnerability" button
  on the Security tab of this repository).
- Or write to **contact@intracherche.fr** with "SECURITY" in the subject.

Include the version, what you did, and what you saw. A proof of concept helps but is not required.
We acknowledge a report within a few working days, and tell you when it is fixed. Please give us
a reasonable time to ship a fix before you disclose it publicly; we credit reporters who wish it.

## Supported versions

Fixes are made on the latest release. Older releases are not patched.

## Scope

In scope: the application, the Python services and the installation scripts in this repository.
Out of scope: findings that need an already-compromised server or administrator account, and
weaknesses in third-party software we only depend on (report those upstream).
