Context:
- Project: Enterprise search engine in Java 21
- Using SOLR
- A Directory Scanner feeds a blocking queue that gets written in a registry (SQLite) which is then indexed by SOLR.

Problem:
In the JUnit Test even when starting the consumer after the producer (scan method) the exception (IllegalStateException: queue full) still occurs
because the producer fills in the queue faster than the consumer can consume it.

Code:
record FileDiscoveredEvent(Path path, long size, Instant lastModified) {}


public class DirectoryScanner {

    private static final Logger log = LoggerFactory.getLogger(DirectoryScanner.class);

    private final FileEventEmitter emitter;
    private final AtomicLong fileCounter = new AtomicLong(0);

    public DirectoryScanner(FileEventEmitter emitter) {
        this.emitter = emitter;
    }

    // Recursively scan directories, single-threaded
    public void scan(Path dir) throws IOException, InterruptedException {
        try (DirectoryStream<Path> stream = Files.newDirectoryStream(dir)) {
            for (Path entry : stream) {
                BasicFileAttributes attrs;
                try {
                    // We don't follow symlinks to avoid potential infinite loops
                    // and to prevent duplicate indexing of the same document
                    attrs = Files.readAttributes(entry, BasicFileAttributes.class, LinkOption.NOFOLLOW_LINKS);
                } catch (IOException e) {
                    log.warn("Cannot read attributes of {}: {}", entry, e.getMessage());
                    continue;
                }

                if (attrs.isDirectory()) {
                    scan(entry);  // recursion
                } else if (attrs.isRegularFile()) {
                    emitter.emit(FileDiscoveredEvent(entry, attrs.size(), attrs.lastModifiedTime().toInstant()));
                }
            }
        }
    }
}
